# JustinForge

A lightweight quality-of-life addon collection for **World of Warcraft Retail — Midnight (至暗之夜)**.
Every feature is an independent module that can be toggled individually — no dependencies, no bloat.

## Features

- **Teleport Gear Auto-Restore** — Automatically swaps teleport items (guild cloaks, Dalaran rings, etc.) back to your previous gear after teleporting.
- **Map Window Center** — Centers the world map window every time it opens.
- **Merchant Window Expand** — Widens the merchant frame to a fixed 4×5 layout (20 items per page).
- **Druid Travel Form Assist** — Auto-cancels Travel Form in flyable areas so you can recast into Flight Form.
- **Hide Learn Messages** — Hides "You have learned / unlearned..." spam in chat.
- **Macro UI Enhance** — Taller macro frame: 6×5 grid (30 macros per page) with a larger edit box.
- **Chat Channel Bar** — A minimalist clickable channel bar (Say / Yell / Party / Raid / World / Roll...) with adjustable position and size.
- **Character Stats Panel** — Always-on stat display (primary, secondary, tertiary, tank stats and real-time movement speed), fully adjustable.
- **Tooltip Enhance** — Class-colored names, guild rank, AFK/DND/offline status, plus M+ score, keystone, item level, dungeon & raid progress and target-of-target on unit tooltips.
- **Hide Crafter Name** — Hides the "<Made by>" signature line on crafted gear tooltips.
- **Quick Focus** — Shift + Left-click units, Blizzard or EllesmereUI unit frames to set focus.
- **Achievement Compare Fix** — Fixes a Blizzard error when clicking the Summary category in achievement comparison mode.
- **Achievement Default Incomplete** — Resets the achievement filter to "Incomplete" every time you open the panel.
- **Achievement Version Filter** — Adds an expansion/patch sub-filter to the personal achievements tab.
- **BigWigs Enhance** — Shows a center-screen icon + countdown for BigWigs / LittleWigs bars in their final 5 seconds, with live preview. Does not affect BigWigs itself.
- **Loot Stack Downward** — Loot roll windows and loot toasts (items / currency / gold / upgrades) stack downward instead of upward.
- **Equipment Alert** — On-screen warnings for gear mistakes: missing Nitro Boosts, missing weapon / off-hand / shield, wrong weapon type or main stat for your spec, etc.
- **Friends List Enhance** — Class-colored character names with level display for Battle.net friends in the Friends panel.

## Installation

1. Copy the `JustinForge` folder into `_retail_/Interface/AddOns/`.
2. Restart the game or run `/reload`.
3. Open **Game Menu → Options → AddOns → BigAddon to toggle each feature.

All settings are saved automatically per profile.

## Compatibility

- **Game version:** Retail — Midnight (至暗之夜)
- **In-game language:** Simplified Chinese (zhCN)
- **Optional support:** BigWigs, EllesmereUI (auto-detected)

# JustinForge（中文说明）

**魔兽世界正式服《至暗之夜》** 轻量实用功能合集。
每个功能都是独立模块，可单独启用或禁用——无第三方依赖，不臃肿。

## 功能列表

- **自动脱下传送装备** — 使用公会披风、达拉然戒指等传送装备后，自动换回传送前的装备。
- **地图窗口居中** — 每次打开世界地图时自动定位到屏幕居中。
- **商人窗口扩展** — 商人界面加宽为固定 4×5 布局（每页 20 件商品）。
- **德鲁伊自动取消旅行形态** — 进入可飞行区域时自动取消变形，重新施放即可切换飞行形态。
- **隐藏学习/遗忘消息** — 隐藏聊天框中「你学会了……」「你遗忘了……」系统提示。
- **宏界面增强** — 宏界面加高：每页 6×5 共 30 个宏，编辑框更大。
- **聊天频道条** — 简约文字频道按钮（说/喊/队/副/团/世/骰等），位置、字号、间距可调。
- **人物属性面板** — 屏幕常态显示主属性、副属性、第三属性、坦克属性与实时移速百分比，可调位置字号。
- **鼠标提示扩展** — 姓名职业染色、公会会阶、离开/忙碌/离线状态；追加 M+ 分数、史诗钥匙、装等、地下城与团本进度、目标的目标。
- **隐藏制造业制造者** — 隐藏制造业装备提示中的绿色「<制造者>」署名行。
- **快速设置焦点目标** — Shift+左键点击单位、暴雪或 EllesmereUI 头像/小队/团队框体设置焦点。
- **成就对比报错修复** — 修复成就界面对比模式下点击「总结」分类报错的问题。
- **成就默认筛选未完成** — 每次打开成就界面时自动将筛选器重置为「未完成」。
- **个人成就版本筛选** — 在成就（个人）标签页追加按资料片/小版本筛选的二级菜单。
- **BigWigs 扩展** — BigWigs / LittleWigs 计时条最后 5 秒时，在屏幕中央显示技能图标与倒计时（支持预览），不影响 BigWigs 本身。
- **拾取窗口向下堆叠** — Roll 窗口与拾取提示（物品/货币/金钱/装备升级）由向上堆叠改为向下堆叠。
- **装备错误提醒** — 检测明显装备错误并屏幕提醒：未附魔氮气推进器、主手/副手/盾牌缺失、武器类型或主属性与专精不符等。
- **好友列表增强** — 战网好友条目角色名按职业染色并追加等级显示。
