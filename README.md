# JustinForge

A lightweight collection of quality-of-life features for **World of Warcraft (Retail)**, compatible with patch 12.0.7 and 12.1.

Each feature is an independent module you can toggle on or off individually — no dependencies, no bloat.

## Features

- **Guild Cloak Auto-Restore** — Automatically swaps your back slot back to the previous item after equipping a guild cloak.
- **Map Window Center** — Repositions the world map window to the center of your screen each time it opens.
- **Merchant Window Expand** — Expands the merchant frame from 10 to 20 items per page, preserving the original layout direction.

## Installation

1. Download or clone this repository.
2. Copy the `JustinForge` folder into your WoW AddOns directory:
   ```
   _retail_/Interface/AddOns/
   ```
3. Launch the game and log in.
4. Open **Game Menu → Options → AddOns** and find the **JustinForge** category.
5. Toggle individual features on or off as desired.

All settings are saved automatically and restored on your next login.

## Compatibility

- **Game version:** Retail 12.0.7 (compatible with 12.1)
- **Localization:** Simplified Chinese (`zhCN`)
